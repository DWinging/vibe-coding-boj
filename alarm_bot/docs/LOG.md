# 🚀 프로젝트: Vibe Coding (BOJ Random Picker Auto message Bot)

## 📅 날짜: 2026-04-07
## 🛠️ 개발 단계: v1.0 랜덤 문체 추천 메시지 전송 기능 구현

### ✅ 오늘 진행 상황 (What I Did)
* **티어별 문제 추출 및 저장**: 
    * 기존 BOJ Random Picker 로직을 활용해 문제 추출 및 저장
    * 실버, 골드, 플래티넘 각각 400문제 씩 추출 후 각각 'silver.json', 'gold.json', 'platinum.json' 파일로 저장
* **중복 문제 추천 방지**: 
    * 서버단 API 호출 시 발생하는 랜덤 중복을 원천 차단하기 위해 400일치의 검증된 문제를 미리 확보하여 순차 배포
    * 날짜를 기준으로 idx를 구분하여 문제 순차 배포
* **무인 자동화**:
    * GitHub Actions의 cron 스케줄러를 활용하여 별도의 서버 유지보수 비용 없이 매일 지정된 시간에 동작하도록 설계

### 🚨 트러블슈팅 (Troubleshooting)
#### GitHub Actions 호출 지연
- **문제** : 메시지가 한국 시간 기준 오전 9시에 발송되도록 설정하였으나, 9시가 아닌 11시에 메시지가 전송되었음
- **원인** : GitHib Actions 호출 요청이 많아 딜레디 된 것으로 추측됨
- **해결** : 메시지 전송 시작을 8시 40분으로 변경. 결과적으로 딜레이가 발생하여 9시 전후로 메시지가 전송되는 것을 확인
