### 🚨 트러블슈팅 (Troubleshooting)

#### 1. Manifest 파일 로드 실패 (Manifest Load Error)
- **문제**: 확장 프로그램 등록 시 "manifest를 로드할 수 없습니다" 에러 발생.
- **원인**: `manifest.json`에 선언된 아이콘이나 HTML 파일이 실제 경로에 존재하지 않아 발생.
- **해결**: 미구현된 파일 선언을 제거하고 파일명을 소문자로 통일하여 경로 일치시킴.

#### 2. API 호출 차단 (Failed to fetch)
- **문제**: 팝업에서 외부 API(`solved.ac`) 요청 시 브라우저가 보안상 이유로 차단.
- **원인**: Manifest V3의 강화된 보안 정책으로, 외부 도메인 통신을 위해서는 명시적인 권한 승인이 필요함.
- **해결**: `manifest.json` 내 `host_permissions` 항목에 `*://*.solved.ac/*`를 추가하여 해결.

#### 3. API 요청 403 Forbidden / 400 Bad Request
- **문제**: 특정 쿼리(`-solved_by:me`) 사용 시 결과가 오지 않거나 에러 발생.
- **원인**: `me` 키워드는 Solved.ac 로그인 세션이 있어야만 동작함.
- **해결**: 개발 단계에서는 해당 쿼리를 제외하고 테스트 진행. 추후 배포 버전에서는 사용자에게 로그인 유도 혹은 사용자 ID 기반 쿼리(`-solved_by:{handle}`)로 대체하기로 결정.

#### 4. Git Push 충돌 (Non-fast-forward)
- **문제**: 원격 저장소의 `README.md`와 로컬의 커밋 히스토리가 달라 푸시 거부.
- **해결**: `--allow-unrelated-histories` 옵션으로 병합하거나, 초기 세팅이므로 `--force` 푸시를 사용하여 동기화.

### 🚨 트러블슈팅 (Troubleshooting)

#### 1. 키보드 입력 불능 (Input Blocking Error)
- **문제**: 프리셋 이름 입력창에서 텍스트 입력이 되지 않거나 특정 키가 먹히지 않는 현상 발생.
- **원인**: 엔터 키 저장을 위해 추가한 `keydown` 이벤트 리스너에서 조건문 없이 `e.preventDefault()`를 호출하여 모든 키 입력을 차단함.
- **해결**: 이벤트 핸들러 내부에서 `if (e.key === 'Enter')` 조건을 확인한 후, 엔터 키일 때만 기본 동작을 막고 저장을 실행하도록 로직 수정.

#### 2. Solved.ac API 쿼리 미지원 (Query Filter Failure)
- **문제**: `s#2000..`(제출 수 2000 이상) 쿼리를 API URL에 직접 포함했으나, 결과가 필터링되지 않거나 빈 결과가 반환됨.
- **원인**: `solved.ac` API의 검색 쿼리 사양에 따라 특정 정렬/필터 필드가 서버 사이드에서 정상 동작하지 않을 수 있음.
- **해결**: 쿼리 수준에서의 필터링을 포기하고, API로부터 받은 50개의 `items` 배열을 JS 단에서 직접 순회하며 `acceptedUserCount * averageTries >= 2000` 수식으로 전수 검사하는 클라이언트 사이드 필터링 방식으로 전환.

#### 3. 고난도 구간 검색 결과 고갈 (Search Result Depletion)
- **문제**: 플래티넘 이상의 고난도 티어에서 '제출 수 2000' 조건을 걸 경우 만족하는 문제가 없어 검색 실패 빈도가 높아짐.
- **원인**: 상위 티어로 갈수록 유저 풀이 적어 절대적인 제출 수가 낮음.
- **해결**: 한 번의 클릭으로 뒤지는 문제 묶음을 기존 150개에서 250개(`MAX_SEARCH_BUNDLES = 5`)로 확장하여 매칭 확률을 높임.

#### 4. 동적 생성 요소의 이벤트 유실 (Event Delegation Issue)
- **문제**: 프리셋 목록을 다시 렌더링한 후, 삭제(`×`) 버튼이 동작하지 않음.
- **원인**: `innerHTML`로 요소를 새로 그릴 때 기존에 바인딩된 이벤트 리스너가 증발함.
- **해결**: 부모 요소인 `#presetList`에 이벤트를 거는 **이벤트 위임(Event Delegation)** 방식을 채택하거나, 렌더링 직후 이벤트를 재바인딩하는 `attachListEvents()` 함수를 호출하여 해결.

### 🚨 트러블슈팅 (Troubleshooting)

#### 1. 구글 웹 스토어 '키워드 스팸' 거절 (Policy Violation: Yellow Argon)
- **문제**: `#Math #DP` 등 알고리즘 태그 나열이 스팸으로 분류되어 업데이트 거절됨.
- **원인**: 메타데이터(설명란) 내에 검색 노출용 키워드를 단순 나열하는 행위는 구글 정책 위반.
- **해결**: 모든 해시태그를 삭제하고, 버전 히스토리(Changelog)와 상세 기능 설명 위주로 텍스트를 재구성하여 재심사 청구.

#### 2. 쿠키 접근 권한 부재로 인한 핸들 추출 실패 (Permission Error)
- **문제**: `getMyHandle()` 함수에서 `chrome.cookies`가 `undefined`로 뜨며 유저 ID를 가져오지 못함.
- **원인**: `manifest.json`에 `cookies` 권한이 누락되었으며, `host_permissions` 설정이 미비함.
- **해결**: `manifest.json`에 `cookies` 권한을 추가하고 `https://solved.ac/*` 호스트 권한을 명시하여 해결.

#### 3. 캐시 만료 로직 부재 (Cache Invalidation Issue)
- **문제**: 사용자가 설정을 바꿨음에도 기존에 저장된 캐시 목록에서 문제가 계속 나옴.
- **원인**: 설정 변경 시 기존 캐시를 무효화(Invalidate)하는 트리거가 없음.
- **해결**: 티어, 정답률, 프리셋 변경 시 `clearCache()`를 호출하여 즉시 캐시를 날리고 다음 클릭 시 API를 새로 호출하도록 수정. 또한 `CACHE_EXPIRE_TIME`을 도입하여 시간 기반 자동 갱신 로직 추가.

#### 4. 대량 페이지 로딩 시 레이트 리밋 (Rate Limit Handling)
- **문제**: 5페이지 연속 호출 시 간헐적으로 API 응답이 끊김.
- **원인**: `solved.ac` API의 단시간 다량 호출 제한에 걸림.
- **해결**: `for` 루프 내에 `await new Promise(res => setTimeout(res, 200))`를 삽입하여 서버 부하를 분산하고 안정적인 수집 환경 조성.
