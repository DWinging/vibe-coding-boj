# Privacy Policy for BOJ Random Picker

**Last Updated: 2026-03-19**

BOJ Random Picker (the "Extension") values your privacy. This Privacy Policy explains how we handle information in connection with our Google Chrome Extension.

### 1. Data Collection and Usage
- **Personal Information:** We do NOT collect, store, or transmit any personally identifiable information (PII) to external servers.
- **Solved.ac Data:** The Extension accesses your `solved.ac` handle via cookies solely to filter out problems you have already solved. This data is processed locally on your device.
- **Storage:** Your preferences (tier range, solving rate, algorithm presets) are stored locally using `chrome.storage`. We do not have access to this data.

### 2. Permissions Justification
- **Storage:** To save user preferences and algorithm presets.
- **Cookies:** To identify the user's solved.ac handle for the "Unsolved Filter" feature.
- **ActiveTab:** To navigate or open the selected problem page on `acmicpc.net`.
- **Host Permissions:** To fetch problem data from the `solved.ac` API.

### 3. Contact
If you have any questions, please contact the developer via this GitHub repository.
